# Quality Bakers Menu

A modern bakery menu management platform built with Next.js, Hono, Prisma and PostgreSQL.

## Features
- Customer menu application
- Admin management portal
- REST API
- Image management
- Search
- Responsive UI

## Tech Stack
- Next.js 15
- React 19
- TypeScript
- Hono
- Prisma
- PostgreSQL
- Turborepo
- pnpm
- Docker
