## Development

The project uses Turborepo and `pnpm` to manage the workspace. 

### Commands

- `pnpm install`: Install dependencies and bootstrap the workspace.
- `pnpm dev`: Start all development servers concurrently.
- `pnpm build`: Build the entire monorepo.
- `pnpm lint`: Run ESLint across all workspaces.
- `pnpm typecheck`: Run TypeScript compilation check across all workspaces.
- `pnpm format`: Format all files with Prettier.
